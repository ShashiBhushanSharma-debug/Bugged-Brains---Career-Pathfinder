# LearnPath AI — Adaptive Learning Path Recommender (AI Engine)

An AI-powered adaptive learning planner that translates natural language goals into prerequisite-aware roadmaps, generates explainable "Why this, why now" justifications, tracks continuous skill mastery via Bayesian Knowledge Tracing (BKT), and dynamically replans the curriculum upon assessment results or feedback.
